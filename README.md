# 勤怠管理システム

シンプルでわかりやすい勤怠管理システムです。HTMLとJavaScriptのみで動作し、バックエンドサーバーは不要です。

## 機能

- ユーザー認証（管理者/従業員）
- 従業員向け機能
  - 出勤/退勤の記録
  - 休憩時間の記録
  - 過去の勤怠記録の閲覧
- 管理者向け機能
  - 全従業員の勤怠データの閲覧
  - データのフィルタリング（日別/月別/従業員別/現場別）
  - 勤怠データの編集と削除
  - CSVでのデータエクスポート

## 使い方

1. このリポジトリをクローンするか、ZIPファイルとしてダウンロードします
2. `index.html` をWebブラウザで開きます
3. 初期ユーザーとしてログインします:
   - 管理者: ユーザーID `admin` / パスワード `admin`
   - 従業員: ユーザーID `employee` / パスワード `employee`

## データの保存について

このアプリケーションはブラウザのローカルストレージにデータを保存します。そのため、ブラウザのキャッシュをクリアするとデータが失われます。実際の業務利用では、サーバーサイドの実装を追加することをお勧めします。

## カスタマイズ

- `js/utils.js` の `createSampleData()` 関数を編集して、サンプルデータをカスタマイズできます
- `index.html` の現場リストを編集して、プロジェクトに合わせた現場名を設定できます
